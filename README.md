# OIBSIP Task 1 - Online Reservation System (Java)

## 📌 Project Overview
This is a console-based **Train Reservation System** developed in Java as part of the **Oasis Infobyte Internship (Java Development)**.

The system allows:
- ✅ User Registration & Login
- ✅ Train Ticket Reservation (with automatic PNR generation)
- ✅ Ticket Cancellation using PNR
- ✅ Database connectivity using MySQL (JDBC)

## 🛠️ Technologies Used
- Java (Core)
- MySQL (Database)
- JDBC (Java Database Connectivity)
- Eclipse IDE

## ⚡ How to Run
1. Clone this repository or download the ZIP.  
2. Import the project into Eclipse.  
3. Make sure XAMPP/MySQL server is running.  
4. Create the required database and tables (`users`, `trains`, `reservations`).  
5. Run `Main.java` and follow the console instructions.
